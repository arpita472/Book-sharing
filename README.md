# Book Sharing Web Application

This is a full-stack web application built with HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- User Registration & Login
- Dashboard Navigation
- Add New Books
- Borrow Books
- View My Books
- View My Requests
- Write Reviews
- View All Reviews
- Profile Page
- Logout System

## How to Run
1. Copy the project folder into `htdocs` inside XAMPP.
2. Create a database named `bookshare_db` in phpMyAdmin.
3. Create required tables: users, books, requests, reviews.
4. Start Apache & MySQL from XAMPP Control Panel.
5. Visit `http://localhost/bookshare/frontend/index.html`
